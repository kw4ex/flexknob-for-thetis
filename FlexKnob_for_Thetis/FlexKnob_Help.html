1. What it is

A small program for Windows 10 and 11 that lets the FlexRadio FlexControl USB tuning knob control Thetis, Thetis HL2 and SDR-VST3. It needs no amplifier and no other radio hardware: just the knob and Thetis.

It is the knob part of the KPA1500 Thetis Bridge (v2.31) as a stand-alone program, for operators who have the knob but not the Elecraft KPA1500 amplifier. It adds a small web page that shows what turning the knob does right now, and what each press does. It can also add a small window inside Thetis that shows the same thing.

2. What it does

  • Turning the knob tunes VFO A in Thetis' own tuning step. A press can switch the knob to VFO B, AF volume, AGC gain, RIT, XIT, tuning step or TX drive. The three lights on the knob show which.
  • 12 presses (the knob press and buttons 1–3, each as a tap, double tap or long press). Each runs a function you choose on the panel.
  • A panel in your browser (http://127.0.0.1:8090) shows what the knob does right now and lets you choose the functions.
  • An optional window inside Thetis ("FlexControl Knob") shows the same thing.

5. Install, step by step

Part A — Get ready (5 minutes)

  1. Close any other program that uses the knob. That means DDUtil (if you use it with the knob) and the knob feature of the KPA1500 Thetis Bridge. Part 6 below shows how to switch the bridge's knob off. The installer can do that for you.
  2. Plug the knob into the computer with its USB cable. Windows normally sets it up by itself (it shows up in Device Manager under Ports).
  3. Turn on Thetis' TCI server. Start Thetis. Click Setup › Serial/Network/Midi CAT › the Network tab. Set the TCI Server to 127.0.0.1:50001, tick TCI Server Running, click Apply, then OK.
  4. Close Thetis the normal way (File › Exit). It is happy to be closed now; the installer may add a window to it.

Part B — Run the installer

  1. In your Downloads folder, right-click FlexKnob_for_Thetis_v1.0.0.zip › Extract All… › Extract.
  2. Open the new FlexKnob_for_Thetis folder and double-click 1_RUN_THIS_Installer.bat.
  3. If Windows says "Windows protected your PC", click More info, then Run anyway. (The installer is a plain text file; you can open it in Notepad to read exactly what it does.)
  4. A window with text opens. It asks a few questions. Press Enter to accept the answer shown in [brackets] unless this guide says otherwise.
  5. Step 1 of 6 — Python. If it says "Found Python…", nothing to do. If not, answer y to let it install Python, or install it yourself from python.org (tick Add python.exe to PATH) and double-click the installer again. It then installs pyserial by itself (internet needed).
  6. Step 2 of 6 — Install folder. Press Enter. The program goes into C:\RadioScripts\FlexKnob_for_Thetis, its own folder, next to your other programs. (Do not choose "Program Files".)
  7. Step 3 of 6 — Only one program can use the knob. If you have the KPA1500 Thetis Bridge, the installer finds it and offers to switch off its knob. Press Enter (yes). Nothing else in the bridge changes. If the bridge is running, the installer shows you the steps to do it yourself (also in Part 6).
  8. Step 4 of 6 — Thetis, start file, shortcuts. "Should the start file also launch… Thetis?" — press Enter (no) to start Thetis your usual way, or y to have one shortcut start both. "Put a shortcut on the Desktop?" — Enter (yes). "Start automatically when you sign in to Windows?" — Enter (no).
  9. Step 5 of 6 — Self-test. Press Enter. After about 30 seconds you should see ALL TESTS PASSED. This test uses a pretend knob and a pretend Thetis; nothing real is touched.
  10. Step 6 of 6 — The knob window inside Thetis (optional). Press Enter (yes) to add it. If Thetis is running the installer offers to close it (Enter; make sure the radio is not transmitting). A backup of Thetis' settings is saved first. Choose n to skip; you can add it later.
  11. At the end it offers to start the knob program now and opens the panel in your browser. Press Enter.

Part C — Check that it works

  1. A window titled FlexControl Knob for Thetis is open (the knob program). Leave it open while you use the radio. To stop the program, click that window and press Q.
  2. Start Thetis (or Thetis HL2 / SDR-VST3) the way you always do. Its TCI server must be on (Part A, step 3).
  3. Open the panel in your browser: http://127.0.0.1:8090 (or double-click Open_Knob_Panel.bat in the install folder). At the top you should see two green labels: Knob connected on COM… and Thetis connected (TCI).
  4. Turn the knob. VFO A should tune. The big text on the panel says VFO A tuning.
  5. Tap button 1. The first light on the knob comes on, the panel says AF volume (master), and turning now changes the volume. Tap button 1 again to go back to VFO A.
  6. If you added the window to Thetis, it shows the same information. If it says FLEXKNOB PROGRAM NOT RUNNING, the knob program is not running.

Part D — Choose what each press does

  1. On the panel, find What each press does. There is one line for each of the 12 presses.
  2. Click the drop-down on a line and pick a function. It is saved at once.
  3. Click Try to run that function as if you had pressed the knob. (Functions that transmit ask you first.)
  4. To go back to the starting settings, click Put all functions back to the defaults.
Every day after that: double-click the FlexKnob for Thetis shortcut on your Desktop (or start_flexknob.bat in C:\RadioScripts\FlexKnob_for_Thetis), then start Thetis.

6. If you also have the KPA1500 Thetis Bridge

The bridge has its own knob feature. Only one program can open the knob, so switch the bridge's knob off and use this program for the knob. The bridge's amplifier features are not affected.

Switch the knob off in the bridge

  1. Start the KPA1500 Thetis Bridge. Open your browser and go to http://127.0.0.1:8080 (the bridge panel).
  2. Click Settings, then find FlexControl tuning knob.
  3. Set the Knob drop-down to Off (not used). It saves by itself and works at once. You do not need to restart the bridge.
  4. Optional: also untick Show the KPA1500 Knob window in Thetis (Settings › Thetis windows › Knob window) and press Rebuild Thetis windows, so Thetis does not show two knob windows.
  5. Now start the knob program from this download. The panel's first label should turn green: Knob connected on COM….

To go back to the bridge's knob

  1. Close the knob program here (click its window and press Q).
  2. In the bridge panel set Knob back to Find it automatically.
The two programs use different names and ports, so they do not overwrite each other: this program's panel is at port 8090 (the bridge's is 8080), its Thetis window is called "FlexControl Knob for Thetis - KW4EX" (the bridge's is "KPA1500 Knob - KW4EX"), and each has its own settings file. One thing to know: each program's Undo puts back the Thetis settings saved before ITS last change, so using one program's Undo can also take away the other's window. Just run that program's Setup again.

7. Knob modes and lights

What turning the knob does is called its mode. The three small lights on the knob (buttons 1-2-3) show the mode:

Turning the knob changesLights (1 · 2 · 3)
VFO A tuning○ ○ ○
VFO B tuning● ○ ●
AF volume (master)● ○ ○
AGC gain (RX1)○ ● ○
RIT (10 Hz per click)○ ○ ●
XIT (10 Hz per click)○ ● ●
Tuning step size● ● ○
TX drive● ● ●

● = on, ○ = off. VFO, RIT, XIT and the tuning step use Thetis' own step. Spun fast, the VFO moves faster (Fast spin on the panel).

8. Safety rules built in

  • TUNE and MOX really make Thetis transmit. Check your antenna or dummy load first. This program does not check for an antenna.
  • TUNE is refused if the radio is already transmitting. It stops by itself after 20 seconds (you can change this on the panel; 0 = never). Pressing it again stops it sooner. The panel shows a big STOP TUNE button while it is on.
  • If Thetis is closed or the link is lost, knob presses that need Thetis do nothing and the panel says so.
  • The panel can only be opened from this computer (127.0.0.1), and only this computer's own web address is accepted.
  • Only one copy of the program runs at a time; a second one says so and stops.

9. Updating and removing

Updating to a newer version

  1. Download the new zip and extract it. Each version has its own name with the version number.
  2. Close the knob program (press Q in its window). The installer can also do this for you.
  3. Double-click the new 1_RUN_THIS_Installer.bat. Choose Continue, and choose Keep your current start options. Your settings (what each press does) are kept.

Removing it

  1. Double-click Uninstall_FlexKnob_for_Thetis.bat in C:\RadioScripts\FlexKnob_for_Thetis.
  2. Answer y to remove the knob window from Thetis (Thetis must be closed; a backup is saved first), and y to delete the program's own files. Nothing else in the folder is touched.

All the functions you can give a press

Pick any of these for each of the 12 presses on the panel.

Knob mode: Knob: AF volume <-> VFO A (toggle); Knob: AGC gain <-> VFO A (toggle); Knob: VFO B <-> VFO A (toggle); Knob: RIT <-> VFO A (toggle); Knob: XIT <-> VFO A (toggle); Knob: tuning step size <-> VFO A (toggle); Knob: TX drive <-> VFO A (toggle); Knob: next mode (VFO A > AF volume > AGC gain); Knob: back to VFO A tuning.

Thetis: Mute on / off; VOX on / off; VFO A lock on / off; Split on / off; RIT on / off; RIT clear (to 0); XIT on / off; Noise reduction (NR) on / off; Noise blanker (NB) on / off; Auto notch (ANF) on / off; Tuning step: larger; Tuning step: smaller; Band up; Band down.

Transmit: MOX on / off (TRANSMITS!); TUNE on / off (TRANSMITS! stops by itself).

Custom: Custom command (type it below).

MOX and TUNE transmit. The panel asks before it "tries" one.

Custom commands

Choose Custom command (type it below) for a press and type a command in the box that appears:

  • A Thetis CAT command that starts with ZZ, for example ZZMA1; (mute on) or ZZTU1; (TUNE on). Thetis' CAT command list is in its Setup › CAT Control help.
  • A TCI command, for example mute:true; or rx_bin_enable:0,true;.

The panel refuses anything that does not look like one of these.

How it works (for the curious)

Windows shows the FlexControl as a serial (COM) port. The program opens it and reads short messages: U; or D; for one click up or down, U03; when spun fast, S;, C;, L; for a tap, double tap or long press of the knob, and X1S;, X2C;, X3L; and so on for buttons 1–3. It sends back I100; (and similar) to set the three lights.

To control Thetis it opens a WebSocket to Thetis' TCI server (127.0.0.1:50001). A turn becomes a Thetis CAT command such as ZZSB; (VFO A up one step), sent with TCI's run_cat_ex. For AF volume and AGC gain it first asks Thetis for the current value, then writes the new one. TUNE uses TCI's tune command.

The panel is a tiny web server on 127.0.0.1:8090. The Thetis window is fed by a few lines of XML sent five times a second to Thetis' Multi Meter I/O (UDP port 50120). The program is one Python file, flexknob_thetis.py, and is the knob part of the KPA1500 Thetis Bridge.
